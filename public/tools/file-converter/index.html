PRIVACY

Your file stays here.

Conversion happens in your browser. No upload endpoint, database, account, paid API or external conversion service is used. Small open-source libraries are loaded from jsDelivr when a conversion needs them.

LIMITS

Know the trade-offs.

  • 25 MB maximum per input file.
  • PDF → DOCX is text-first, not pixel-perfect.
  • Scanned PDFs are detected when no selectable text is found; OCR reconstruction is not claimed.
  • Animated GIF input converts as its first decoded frame.
  • Workbook sheets are never silently merged.
BROWSER-FIRST UTILITY

No conversion server is involved. Your files are held temporarily by this page and released when you leave or reset the tool.
