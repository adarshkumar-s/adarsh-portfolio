What it was

The original site was an HTML/CSS/JavaScript portfolio served through a small Express server. Its homepage introduced Adarsh as a web developer, included a visual character collection, and embedded the Todo app.

What changed

The current portfolio separates professional project work from experiments and from the historical portfolio itself. That keeps the original site visible without confusing it with today's platform.

Original source

The original files are preserved under /archive/previous-portfolio/ in this branch. The archive is intentionally kept close to the source files rather than rewritten.

Engineering notes

The old server used Express static serving and a dedicated Todo route. The old homepage linked directly to the stored visual assets and an earlier LinkedIn/WhatsApp contact flow. Those historical links remain inside the archive and are not presented as current contact details.

Lessons from the transition

The rebuild turns a single-page portfolio into a platform with explicit surfaces for current work, experiments, tools, writing, verified stats and contact.
