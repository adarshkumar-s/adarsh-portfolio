Character Gallery

A contained visual experiment using existing character imagery from the original portfolio.

Stack
HTMLCSSResponsive imagery

Problem

The original homepage mixed portfolio identity with a moving collection of character cards and image assets.

Solution

The rebuild separates that playful material into a clearly labeled visual experiment, preserving the assets without presenting them as invented professional projects.

Features

  • Responsive image presentation.
  • Clear distinction between experiment and professional work.
  • Existing assets are reused rather than discarded.
