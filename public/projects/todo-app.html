Todo App

A client-side task manager preserved as a live browser application.

HTMLCSSJavaScriptlocalStorage

Overview

The application stores tasks in the browser and supports adding, editing, completing and deleting tasks, plus search, All / Active / Completed filters, sorting, priorities, categories, due dates, Mark all complete and Clear completed.

Implementation

The current presentation uses semantic HTML and a small JavaScript state loop. Task titles and metadata are inserted with DOM nodes rather than unsafe HTML rendering. State is persisted with localStorage.

Design decisions

  • No account or server is required.
  • The browser remains the source of truth for this local application.
  • The case-study route explains the project while the standalone route keeps it immediately usable.

Accessibility and resilience

The application provides keyboard-focusable controls, responsive layouts and reduced-motion handling. Existing task data can be migrated from supported legacy localStorage keys into the current storage key.
