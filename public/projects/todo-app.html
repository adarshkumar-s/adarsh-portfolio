Todo App

A small client-side task manager preserved from the original project and kept usable as a live browser application.

HTMLCSSJavaScriptlocalStorage

Overview

The application stores tasks in the browser, supports All / Active / Completed filters, completion toggles, deletion and clearing completed items.

Implementation

The current presentation uses semantic HTML and a small JavaScript state loop. Task titles are inserted with DOM text nodes, avoiding unsafe HTML rendering. State is persisted with localStorage.

Design decisions

  • No account or server is required.
  • The browser remains the source of truth for this local experiment.
  • The case-study route explains the project while the standalone route keeps it immediately usable.

Challenges

The original implementation rendered task text through an escaping helper. The rebuild retains the same security intent with direct DOM node creation.

Future improvements

Editing, due dates, import/export, keyboard shortcuts and automated browser tests are plausible next steps.
