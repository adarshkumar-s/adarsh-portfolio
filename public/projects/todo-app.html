CASE STUDY / 01

Task Tracker

A focused browser Todo application, retained from the original portfolio and given a cleaner presentation.

Technology
HTMLCSSJavaScriptlocalStorage

Problem

Provide a small task workflow that works without accounts, a database or a backend.

Solution

A client-side app keeps tasks in browser localStorage and renders All, Active and Completed views.

Features

  • Add tasks and submit with Enter.
  • Toggle completion and delete individual tasks.
  • Filter the task list and clear completed items.
  • Render user text through DOM text nodes rather than unsafe HTML.

Architecture

One semantic HTML document, one stylesheet and one JavaScript module. State is local to the browser; there is no external API.
