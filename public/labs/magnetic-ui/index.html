LAB / PROTOTYPE 02

Magnetic UI.

A small physics-inspired study of proximity: controls lean toward the pointer inside a defined field, then return to their resting positions.

Move a pointer · keyboard focus remains normal
WHAT'S HAPPENING

Proximity controls the pull.

Each control has an independent rest position. Only its transform changes, which keeps document layout, click targets and keyboard order stable while the motion settles through a small spring model.
